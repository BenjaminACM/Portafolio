# BCM
Portafolio de Benjamín Corrales Mira. Sitio estático sin dependencias.

## Vista local

Ejecuta `python3 -m http.server 8000` desde la raíz y abre
`http://localhost:8000/`.

## Configuración

- Proyectos. Agrega entradas al arreglo `projects` de `portfolio.js`.
- Captura de M&R Consultores. Guarda una captura real del encabezado y portada
  en `images/myr-consultores.webp` (recomendado 1280 × 720) y asigna
  `'./images/myr-consultores.webp'` al campo `image` del proyecto.
- Contacto. Completa las URL oficiales en el arreglo `contacts` de
  `portfolio.js`. Usa `mailto:` para el correo y direcciones HTTPS para
  WhatsApp e Instagram. Cada botón aparece cuando su enlace está configurado.
